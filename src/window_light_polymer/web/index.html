THE IMPORTANT CAVEAT

123 polyurethane records

Every polyurethane record comes from one upstream source and carries the dataset's lowest-confidence reliability label. A useful benchmark can still be built—but not a formulation claim.

SERIOUS MODELING · ON DECK

The additive-migration model will plot a temperature-dependent distribution of accessible free-volume openings and overlay a user-supplied additive diameter. DFT can parameterize interactions; molecular dynamics must generate the opening and diffusion curves. Crossing the size line is only a geometric screen—partitioning and transport time are still required to predict leaching.

READ THE NETWORK

Same chemical family.
Different topology.

“Polyurethane” names the linkage family. “Thermoplastic” or “thermoset” describes the larger architecture those linkages build.

TPU: physical crosslinks

Linear or lightly branched chains alternate flexible soft segments with more polar hard segments. Hard segments can cluster through hydrogen bonding and other intermolecular forces.

Thermoset: covalent crosslinks

Components with functionality above two create permanent junctions between chains. The resulting three-dimensional network cannot separate into melt-flowing molecules.

THE REACTION MOTIF

HO—Rsoft—OH + OCN—Rhard—NCO forms [—O—C(=O)—NH—Rhard—NH—C(=O)—O—Rsoft—]n

Connectivity is the switch.

Difunctional building blocks favor long chains. Adding multifunctional polyols or isocyanates introduces branch points; enough branch points create a thermoset network.

Polyether soft segments place ether oxygens along a flexible backbone. They change segment behavior, but they do not by themselves decide whether the whole polyurethane is a thermoplastic or thermoset.

WHAT THE SKETCH LEAVES OUT

A structure class is not a recipe.

Exact properties depend on reactant identity and functionality, hard-to-soft segment ratio, molecular weight, stoichiometry, catalysts, additives, morphology, cure history, moisture, and test temperature. Use this explorer to reason about architecture—not to choose a formulation or processing window.

Polly is an exploratory PALS/free-volume research preview. It is not a validated migration or leaching predictor, formulation, process specification, exposure assessment, or product-safety tool.
